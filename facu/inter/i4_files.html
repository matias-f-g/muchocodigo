LOS ARCHIVOS ORIGINALES + REFERENCIAS BIBLIOGRÁFICAS

Cada tanto, cuando leo algún manual y las imágenes se quedan un poco cortas, digo "uh, estaría piola que esto tenga algún gráfico interactivo o algo así". Y bueno, eso es un poco lo que intenté hacer con estos programas.

Probablemente te van a servir si estás leyendo el Data Structures and Algorithm Analysis in Java (3rd Edition) de Mark Allen Weiss, o si estás cursando "Algoritmos y Estructuras de Datos" (en la UNLP), ya que casi todos los algoritmos salieron de ese libro o de esa materia. Pero bueno, la idea es jugar un poco con las estructuras de datos, aunque nunca las hayas visto en la vida.

Los programas originales los escribí en Python, usando la librería Pygame (que aunque ya es un poco vieja, está genial para empezar a aprender a programar juegos o programas con gráficos sencillos). Para aprender Pygame, te recomiendo el libro Making Games with Python & Pygame, del gran Albert Sweigart. El tipo no solo escribe libros para hacer todo lo que se te ocurra en Python, sino que, además de eso, los comparte gratis en su página Invent with Python.

Volviendo a los programas de esta página, más abajo te dejo los archivos originales hechos en Python, por si querés revisar algún algoritmo o modificar alguna cosa. Eso sí: para que funcionen deberías tener instalado Python y la librería Pygame, que es muy fácil de instalar. Si tenés Linux, son un par de comandos. Si tenés Windows, primero instalate Linux, y listo, después son un par de comandos.
